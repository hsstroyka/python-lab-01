# Лабораторная работа №1 - калькулятор и конвертер величин на Python
## Описание проекта
Проект представляет собой консольный пакет, содержащий два независимых вычислительных ядра:

**1. Калькулятор выражений (`calc`)**: вычисляет математические выражения с поддержкой унарных и бинарных операций, вещественных чисел и соблюдением приоритетов через стек (RPN).

**2. Конвертер величин (`convert`)**: переводит значения между различными единицами длины (`mm`, `cm`, `m`, `km`), массы (`g`, `kg`) и температуры (`c`, `f`, `k`).

## Настройка и запуск

Перед запуском утилит в терминале необходимо задать путь поиска модулей:
```
\$env:PYTHONPATH="src"
```
Также если вы используете например PyСharm, то можете просто открыть проект и написать:
```
cd src\
```
## Примеры использования:
**Запуск калькулятора выражений:**

Например, чтобы найти значение выражения 2 + 3, нужно написать:
  ```
  python -m toolkit calc 2 + 3
  ```
В вычисляемом выражении можно не ставить кавычки и ставить сколько угодно пробелов или не ставить их, так как они игнорируются.

**Запуск конвертера величин:**

Например, чтобы найти сколько граммов в полутора килограммах, нужно написать:

  ```
  python -m toolkit convert 1.5 --from kg --to g
  ```
**Показать встроенную справку:**
  ```
  python -m toolkit --help
  ```
или
```
python -m toolkit -h
```
## Тестирование и качество кода
Проект полностью покрыт автоматическими тестами, которые включают тесты модулей и CLI интерфейса.

**Запуск тестов:**
  ```
  python -m pytest
  ```
**Проверка стиля кода с помощью ruff check:**
  ```
  python -m ruff check .
  ```
